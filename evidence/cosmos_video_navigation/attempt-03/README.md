# Cosmos3 连续未来导航视频验证：Attempt 03

本轮从与 Attempt 01/02 相同的 HouseWorld 巡游历史出发，在一个 `video2video` 请求中生成更长的单段未来视频，避免分段续写和拼接边界。

## 配置

- 模型：本机 `Cosmos3-Edge`
- 条件历史：5 帧、10 FPS，`condition_frame_indexes_vision=[0,1]`
- 目标条件：`target_image.jpg` 提取出的充电桩外观、ID 560 和局部场景语义
- 输出：121 帧、10 FPS、12.1 秒、480p 16:9（实际 `832 x 480`）
- 采样：16 steps，guidance 4.0，shift 5.0，seed 560
- guardrails：关闭，仅用于离线机器人仿真画面生成

- [连续视频](output/go2w_target_video_prediction_12s_seed560/vision.mp4)
- [关键帧](keyframes.jpg)
- [逐段接触表](contact_sheet.jpg)
- [末帧](frame_120.jpg)

- [机器可读验收](verification.json)

推理成功，墙钟时间 45.86 秒；其中 diffusion sampling 约 23.4 秒。输出为 H.264、`832 x 480`、121 帧、10 FPS、12.1 秒，文件大小 11,272,047 bytes。
其中前 5 帧（0.5 秒）是模型保留的条件历史，第 5 至 120 帧是 116 帧、11.6 秒的生成未来。

## 验收

### 通过：连续接近

- 第 5 至 120 帧为生成段，保持同一墙面、木地板、踢脚线和目标所在区域；没有生成段硬切或完全重复帧。
- `freezedetect(n=0.002,d=0.2)` 检出 `5.0-5.3 s`、`5.5-5.7 s` 和 `11.7-12.0 s` 三个低变化区间；它们不是完全重复帧，末段区间与减速趋势一致。
- 目标顶部标牌代理从约 26.0 px 增至 91.5 px，线性尺度约放大 3.52 倍。
- 末帧目标水平中心距离画面中心约 16.2 px，只占画宽 1.95%，基本居中。
- 末帧目标形成大幅近景，视觉上进入目标附近。

### 部分通过：末端减速

- 最后两秒 LK 中值运动约 1.49 px/帧，相比第 60 至 80 帧约 4.42 px/帧下降约 66%。
- 最后约 0.3 至 0.4 秒接近静止，但仍没有完全重复帧，末帧仍存在小幅视觉漂移。

### 不通过：正确、安全到达

- ID 560 只在输入历史帧中可解码；生成段被误读为 694、660、441、404、412、107 等 ID。
- 充电桩从窄腿结构逐渐形变成宽立柱，目标身份和几何没有严格保持。
- 最终对位板不可见，目标下部被画面底边截断，无法从 RGB 视频判断停距、对位或是否碰撞。

因此本轮准确结论是：**生成了连续的目标导向未来视频，并预测到目标近景、基本居中和末端近静止；没有证明已导航到正确目标位置并安全停车。**

## 运行边界

本轮没有连接 ROS，也没有执行任何底盘、下蹲或模态切换动作。若用于 Go2-W 闭环，应把长视频预测改为 4/8/16 帧滚动时域，在每个执行前缀前重新读取真实传感器，并由安全门控和 Reasoner 决定是否执行、停车及切换模态。
