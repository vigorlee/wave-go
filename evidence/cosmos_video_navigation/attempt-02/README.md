# Cosmos3 连续未来导航视频验证：Attempt 02

Attempt 01 的 25 帧、256p 输出连续且保持场景，但目标只缓慢变大，ArUco 无法从生成帧中解码。本轮固定同一巡游视频、目标语义与 seed，只改变：

- 输出从 25 帧扩到 61 帧（10 FPS，6.1 秒）。
- 分辨率从 256p 提高到 480p。
- diffusion steps 从 12 提高到 16。
- prompt 明确要求持续靠近、最后一秒减速停车，并保留 ID 560 外观。

输出仍是离线世界模型预测，不连接 ROS、不发布控制命令。

## 实测结果

- 输出：H.264，`832 x 480`，61 帧，10 FPS，6.1 秒。
- 墙钟时间：24.91 秒；最大常驻内存：6,196,592 KiB。
- 生成延续段为第 5 至 60 帧；没有完全重复帧、冻结区间或生成段硬切。
- 生成段灰度相邻帧 MAD 均值为 10.757948，SSIM 均值为 0.743039。
- 目标标记候选线性尺度从约 22.7 px 增至 46.7 px，约放大 2.06 倍，并趋近画面水平中心。
- 最后一秒目标仍放大约 18%，LK 中值运动约 7.24 px/帧，因此没有停车证据。
- ID 560 只在历史条件帧 4 被解码；生成帧中没有 ID 560，并曾误解码为 568 和 230。

结论：本轮通过“连续接近目标”验收，但不通过“到达并停车”和“保持可解码 ID 560”验收。详细指标见
[`verification.json`](verification.json)。
